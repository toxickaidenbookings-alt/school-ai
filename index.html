AI chat setup

The Chat tab calls the Anthropic API directly from your browser. Your API key is stored only in this browser's local storage — it is never sent anywhere except to Anthropic. On a shared or managed school computer, local storage can be cleared between sessions and the key is visible to anyone with access to this browser, so don't use a key you're not comfortable having on a shared machine.

Canvas sync

Pulls your upcoming assignments and due dates from Canvas straight into the Planner. Needs a personal access token, not just the link — in Canvas go to Account → Settings → New Access Token, generate one, and paste it below with your school's Canvas link. The token is stored only in this browser's local storage and sent only to your Canvas domain. Some schools block direct browser requests to Canvas (CORS), and some disable student access tokens entirely (the button shows greyed out) — if either is true for you, use Planner → Paste in from Canvas instead, which needs no token at all.

Your data

Everything (planner, flashcards, GPA, key) lives in this browser's local storage — nothing is uploaded. If this device resets often, copy your data out as a backup and paste it back in later.
